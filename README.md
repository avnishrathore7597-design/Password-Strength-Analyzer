# Password-Strength-Analyzer
Password Strength Analyzer is a Python-based tool that evaluates the strength of a user-entered password. It checks password length, character diversity, and complexity to classify passwords as Weak, Medium, or Strong.

# Features
1.Password length validation
2.Uppercase letter detection
3.Lowercase letter detection
4.Number detection
5.Special character detection
6.Password strength classification
7.Strong password suggestions

# Technologies Used
1.Python 3
2.Regular Expressions (re)
3.Random Module
4.String Module
# How to Run

python password_analyzer.py
